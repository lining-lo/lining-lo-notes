## 1. 方法的介绍

### 1.1 什么是方法

方法（method），也叫函数，是一段具有独立功能的代码块，不调用就不执行。

### 1.2 为什么要使用方法

如果所有功能都直接写在 `main` 方法中，代码会非常臃肿。以"黑马商城"为例，需要实现 4 个功能：

1. 查看全部商品
1. 上架商品
1. 下架商品
1. 修改商品

每个功能大约 50 行代码，全部堆在 `main` 方法中：

```java
public class VariableDemo {
    public static void main(String[] args) {

	查看全部商品 (50行代码)

	上架商品 (50行代码)

	下架商品 (50行代码)

	修改商品 (50行代码)



    }
}
```

这样的代码非常臃肿。

把每个功能封装成方法后，`main` 方法中只需要调用方法即可：

```java
public class Test {
    public static void main(String[] args) {

	showGoodsInfo();

	addGoods();

	deleteGoods();

	updateGoods();

    }


    /** 查看全部商品 */
    public static void showGoodsInfo(){ ... }

    /** 上架商品 */
    public static void addGoods(){ ... }

    /** 下架商品 */
    public static void deleteGoods(){ ... }

    /** 修改商品 */
    public static void updateGoods(){ ... }
}
```

### 1.3 方法的作用

- 可以将挤在一起的臃肿代码，按照功能进行分类管理，提高维护性
- 提高代码的复用性

## 2. 方法的基本定义和调用

### 2.1 方法的定义格式

```java
public static void 方法名() {
    // 方法体
}
```

举例：

```java
public static void show() {
    ...
}
```

### 2.2 方法的调用格式

```java
方法名();
```

举例：

```java
show();
```

### 2.3 案例：方法计算两个整数最大值

需求：定义一个方法，方法中定义两个整数变量，求出最大值并打印在控制台。

分析：

- 根据格式编写方法，方法名自己给出（见名知意，小驼峰命名法）
- 方法内部定义出两个 `int` 类型变量
- 使用三元运算符求出最大值
- 调用该方法，让内部的逻辑执行起来

## 3. 方法的执行流程

### 3.1 内存中的两个重要区域

- 方法区：字节码文件加载时进入的内存
- 栈内存：方法运行时入栈，方法运行结束出栈

方法的存放与运行：

- 方法没有被调用的时候，在方法区中的字节码文件中存放
- 方法被调用的时候，需要进入到栈内存中运行

### 3.2 案例一：getMax 方法的调用流程

代码：

```java
public class MethodDemo1 {
    public static void main(String[] args) {
        System.out.println("开始");
        getMax();
        System.out.println("结束");
    }

    public static void getMax() {
        int num1 = 10;
        int num2 = 20;
        int max = num1 > num2 ? num1 : num2;
        System.out.println(max);
    }
}
```

执行流程：

1. `main` 方法入栈，执行 `System.out.println("开始")`，控制台输出"开始"
1. 执行 `getMax()` 调用，`getMax` 方法进入栈内存（入栈）
1. 在 `getMax` 中定义 `num1`、`num2`，计算 `max`，打印最大值 20
1. `getMax` 执行完毕，从栈内存中移除（出栈）
1. 回到 `main` 方法继续执行 `System.out.println("结束")`，控制台输出"结束"

控制台最终输出：

```text
开始
20
结束
```

### 3.3 案例二：方法之间的互相调用

代码：

```java
public class MethodDemo2 {
    public static void main(String[] args) {
        study();
    }

    public static void sleep(){
        System.out.println("睡觉");
    }

    public static void eat(){
        System.out.println("吃饭");
    }

    public static void study(){

        eat();

        System.out.println("学习");

        sleep();

    }
}
```

执行流程：

1. `main` 方法入栈，调用 `study()`，`study` 入栈
1. `study` 调用 `eat()`，`eat` 入栈，打印"吃饭"，`eat` 出栈
1. 回到 `study`，打印"学习"
1. `study` 调用 `sleep()`，`sleep` 入栈，打印"睡觉"，`sleep` 出栈
1. `study` 执行完毕出栈，`main` 执行完毕出栈

控制台最终输出：

```text
吃饭
学习
睡觉
```

小结：

- 方法区：字节码文件加载时进入的内存
- 栈内存：方法运行时入栈，方法运行结束出栈

## 4. 带参数的方法

### 4.1 为什么需要参数

之前的 `getMax` 方法把 `num1` 和 `num2` 写死在了方法内部，只能计算 10 和 20，代码灵活性差。

改造为带参数的方法后，调用时传入不同的值，即可计算任意两个整数的最大值：

```java
public class MethodDemo1 {
    public static void main(String[] args) {

        getMax(10,20);

        getMax(30,40);

    }

    public static void getMax(int num1, int num2) {

        int max = num1 > num2 ? num1 : num2;

        System.out.println(max);

    }
}
```

### 4.2 定义格式

一个参数：

```java
public static void 方法名 (数据类型 变量名) {
    // 方法体
}
```

举例：

```java
public static void call (String name) {
    ...
}
```

多个参数：

```java
public static void 方法名(数据类型 变量名1，数据类型 变量名2... ) {
    // 方法体
}
```

举例：

```java
public static void add (int a, int b) {
    ...
}
```

### 4.3 调用格式

一个参数：

```java
方法名(参数);
```

举例：

```java
call("钢门吹雪");
```

多个参数：

```java
方法名(参数1, 参数2);
```

举例：

```java
add(10,20);
```

### 4.4 带参数的方法内存图解

代码：

```java
public class MethodDemo2 {
    public static void main(String[] args) {

        getMax(10,20);

        System.out.println("--------");

        getMax(30,40);
    }

    public static void getMax(int num1, int num2) {

        int max = num1 > num2 ? num1 : num2;

        System.out.println(max);
    }
}
```

执行流程：

1. `main` 入栈，调用 `getMax(10, 20)`，`getMax` 入栈，实参 10、20 分别赋值给形参 `num1`、`num2`
1. 计算 `max = 20` 并打印，`getMax` 出栈
1. 回到 `main`，打印"--------"
1. 再次调用 `getMax(30, 40)`，形参 `num1 = 30`、`num2 = 40`，打印 40，`getMax` 出栈

控制台最终输出：

```text
20
--------
40
```

### 4.5 形参和实参

- 形参：全称形式参数，是指在定义方法时，所声明的参数
- 实参：全称实际参数，调用方法时，所传入的参数

小结：带参数的方法可以提高方法的灵活性。

## 5. 带返回值的方法

### 5.1 为什么需要返回值

A 方法产生的数据，B 方法想要使用的话，就需要定义带返回值的方法。

错误示例：`methodA` 中计算出的 `sum`，`methodB` 无法使用

```java
public static void methodA (int a, int b) {
    int sum = a + b;
    ...
}

public static void methodB () {
    System.out.println(sum % 2 == 0);

}
```

正确示例：通过 `return` 把 `sum` 返回，`methodB` 用变量接收

```java
public static void methodA (int a, int b) {
    int sum = a + b;
    return sum;
}

public static void methodB () {
    int result = methodA(10,20);
    System.out.println(result % 2 == 0);
}
```

### 5.2 定义格式

```java
public static 数据类型 方法名 (数据类型 变量名1，数据类型 变量名2... ) {
      return 数据值;
}
```

举例：

```java
public static double getNum () {
    return 12.3;
}
```

```java
public static int add (int a, int b) {
    int c = a + b;
    return c;
}
```

### 5.3 调用格式

直接调用：

```java
方法名(参数...);
```

范例：

```java
add(10,20);
```

用变量接收调用：

```java
数据类型 变量名 = 方法名(参数...);
```

范例：

```java
int result = add(10,20);
```

### 5.4 小结

- A 方法中的数据，如果 B 方法想要使用的话，就需要设计返回值
- 通过 `return` 关键字，将结果数据返回
- 数据返回到方法的调用处

## 6. 方法通用定义格式

### 6.1 通用格式

```java
public static 返回值类型 方法名( 参数 ) {
   方法体;
   return 数据 ;
}
```

### 6.2 用"做面包"理解方法

- 参数：制作材料（面粉，酵母，糖...）
- 方法体：使用材料干活（搅拌...）
- 返回值：成品（面包）

### 6.3 定义方法时，要做到两个明确

- 明确参数：主要是明确参数的类型和数量
- 明确返回值类型：主要是明确方法操作完毕之后是否有结果数据，如果有，写对应的数据类型，如果没有，写 `void`

### 6.4 调用方法时

- `void` 类型的方法，直接调用即可
- 非 `void` 类型的方法，推荐用变量接收调用

### 6.5 练习

- 需求 1：设计一个方法，方法能够计算出 2 个小数的和
- 需求 2：设计一个方法，能够计算出 3 个整数的最小值
- 需求 3：设计一个方法，方法能够打印出用户的个人信息（姓名，年龄，身高，性别）

## 7. 方法注意事项

- 方法不调用就不执行
- 方法与方法之间是平级关系，不能嵌套定义
- 方法的编写顺序和执行顺序无关
- 方法的返回值类型为 `void`，表示该方法没有返回值，没有返回值的方法可以省略 `return` 语句不写
- 如果要编写 `return`，后面不能跟具体的数据
- `return` 语句下面，不能编写代码，因为永远执行不到，属于无效的代码

正确示例：`void` 方法省略 `return`

```java
public class MethodDemo {
    public static void method() {
        //代码片段

    }
}
```

正确示例：`void` 方法编写不带数据的 `return`

```java
public class MethodDemo {
    public static void method() {
        //代码片段
	return;
    }
}
```

错误示例：`void` 方法的 `return` 后面跟了数据

```java
public class MethodDemo {
    public static void method() {
        //代码片段
	return 100;
    }
}
```

错误示例：`return` 后面编写了永远执行不到的代码

```java
public class MethodDemo {
    public static void method() {
        //代码片段
	return;
	System.out.println("卑微代码");
    }
}
```

## 8. 方法重载

### 8.1 需求

提供 4 个计算方法，方法功能如下：

1. 计算两个整数相加的和
1. 计算两个小数相加的和
1. 计算三个整数相加的和
1. 计算三个小数相加的和

### 8.2 不使用重载：方法名各不相同

```java
public class Test {
    public static int add1(int a, int b) {
        return a + b;
    }

    public static double add2(double a, double b) {
        return a + b;
    }

    public static int add3(int a, int b, int c) {
        return a + b + c;
    }

    public static double add4(double a, double b, double c) {
        return a + b + c;
    }
}
```

### 8.3 使用重载：方法名相同，参数不同

```java
public class Test {
    public static int add(int a, int b) {
        return a + b;
    }

    public static double add(double a, double b) {
        return a + b;
    }

    public static int add(int a, int b, int c) {
        return a + b + c;
    }

    public static double add(double a, double b, double c) {
        return a + b + c;
    }
}
```

调用方法的时候，Java 虚拟机会通过参数的不同来区分同名的方法：

```java
add(10,20);
add(10,20,30);
add(12.3,12.3);
add(12.3,12.3,12.3);
```

### 8.4 重载的定义

- 在同一个类中，定义了多个同名的方法，但每个方法具有不同的参数类型或参数个数，这些同名的方法，就构成了重载关系（Overload）
- 简单记：同一个类中，方法名相同，参数不同的方法
- 参数不同：个数不同、类型不同、顺序不同
- 注意：识别方法之间是否是重载关系，只看方法名和参数，跟返回值无关

### 8.5 重载判断练习

判断 1：不是重载（参数相同，只是返回值不同，判断重载不看返回值）

```java
public class MethodDemo {
    public static void fn(int a) {
        //方法体
    }
    public static int fn(int a) {
        //方法体
    }
}
```

判断 2：是重载（参数类型不同）

```java
public class MethodDemo {
    public static void fn(int a) {
        //方法体
    }
    public static int fn(double a) {
        //方法体
    }
}
```

判断 3：是重载（参数个数不同）

```java
public class MethodDemo {
    public static float fn(int a) {
        //方法体
    }
    public static int fn(int a , int b) {
        //方法体
    }
}
```

判断 4：不是重载（不在同一个类中）

```java
public class MethodDemo01 {
    public static void fn(int a) {
        //方法体
    }
}
public class MethodDemo02 {
    public static int fn(double a) {
        //方法体
    }
}
```

判断 5：是重载（参数顺序不同）

```java
public class MethodDemo {
    public static void fn(int a, double b) {
        //方法体
    }
    public static void fn(double a, int b) {
        //方法体
    }
}
```

判断 6：不是重载（参数名不同，但参数类型、个数、顺序都相同）

```java
public class MethodDemo {
    public static void fn(int a, double b) {
        //方法体
    }
    public static void fn(int c, double d) {
        //方法体
    }
}
```

### 8.6 方法重载的好处

不用记忆过多繁琐的方法名字。比如 `System.out.println` 本身就可以输出不同类型的数据，就是典型的重载方法：

```java
public class MethodDemo {
    public static void main(String[] args) {
      //输出调用
      System.out.println(10);
      System.out.println(10.1);
      System.out.println(true);
    }
}
```

小结：

- 问题：方法重载看返回值吗？不看，只看参数类型、参数个数、参数顺序
- 问题：方法重载有啥好处呢？不需要记忆太多方法名字

## 10. 本章重点回顾

- 方法（函数）：一段具有独立功能的代码块，不调用就不执行
- 方法定义通用格式：`public static` + 返回值类型 + 方法名 + 参数列表 + 方法体
- 方法调用：`void` 方法直接调用，非 `void` 方法推荐用变量接收
- 形参在定义方法时声明，实参在调用方法时传入
- 定义方法两个明确：明确参数（类型和数量）、明确返回值类型（有结果写类型，没结果写 `void`）
- 方法不调用就不执行；方法之间平级，不能嵌套定义；`return` 后不能写代码
- 方法重载：同一个类中，方法名相同、参数不同（个数、类型、顺序），与返回值无关
