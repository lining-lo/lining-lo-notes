## 1. 面向对象介绍

### 1.1 什么是面向对象

Java 面向对象（Object-Oriented Programming，简称 OOP）是 Java 编程语言的核心思想之一。它**通过“对象”来组织代码，使程序更模块化、可重用、易维护**。

核心思想是：**把现实世界中的事物，都抽象成「类」(模版)和「对象」（利用模版创建的实体对象）**，以「事物」为核心，关注**事物有什么特征、能做什么行为**，而不是关注步骤。

我们之前缩写的代码是面相过程编程的，我们只需要：关注「步骤」，我要做一件事，需要**第一步做什么、第二步做什么、第三步做什么**，是「执行者」思维。

### 1.2 为什么要学习面向对象

1. 因为生活中我们解决问题时，就是采用这种指导思想去解决的
1. 所以写程序去解决问题时，如果也能采用这种指导思想
1. 就会使编程变得非常简单，程序也便于人理解

### 1.3 猜数字游戏：使用已有对象

1. `Scanner` 和 `Random` 都是 Java 已经写好的类，可以直接使用
1. 那我要解决的问题，人家 Java 没提供怎么办？——这就需要学习自己如何设计对象

```java

            System.out.println("猜中了");
```

## 2. 类和对象

### 2.1 什么是类

1. Java 中想要创建对象，必须先要有类的存在
1. 类指的是一组相关属性和行为的集合，我们将其理解为是一张对象的设计图

### 2.2 类和对象的关系

1. Java 中需要根据类创建对象
1. 一个类可以创建出多个对象

### 2.3 类的组成

1. 成员变量：跟之前定义变量的格式一样，只不过位置需要放在方法的外面
1. 成员方法：跟之前定义方法的格式一样，只不过需要去掉 `static` 关键字

```java
public class Student {
    String name = "张三";
    int age = 23;

    public void study(){
        System.out.println("学习Java");
    }

    public void eat(){
        System.out.println("吃饭");
    }
}
```

小结：

1. 类的组成：属性、行为
1. 属性：成员变量，指描述事物的名词
1. 行为：成员方法，指描述事物的动词

### 2.4 创建对象

创建对象格式：`类名 对象名 = new 类名();`

### 2.5 使用对象

1. 成员变量的使用格式：`对象名.变量名;`
1. 成员方法的使用格式：`对象名.方法名(实际参数);`

```java
public class TestStudent {
    public static void main(String[] args) {

        // 创建对象格式:
        // 类名 对象名 = new 类名();
        Student stu = new Student();

        // 使用成员变量格式:
        // 对象名.变量名
        System.out.println(stu.name);
        System.out.println(stu.age);

        stu.name = "李四";
        stu.age = 24;

        // 使用成员方法格式:
        // 对象名.方法名(实际参数);
        stu.study();
        stu.eat();

    }
}
```

## 3. 类和对象内存图

### 3.1 单个对象内存图

1. 栈内存：局部变量 `Student stu` 中保存的是对象的地址值（例如 7ef20235）
1. 堆内存：存放对象本身，成员变量初始有默认值（`String name` 为 `null`，`int age` 为 0），赋值后变成实际值（张三、23）
1. 方法区：存放 `Student.class`，其中有成员变量和成员方法；对象中的成员方法引用方法区中的方法地址

```java
public class Student {
    String name;
    int age;
    public void study(){
        System.out.println("学习Java");
    }
    public void eat(){
        System.out.println("吃饭");
    }
}
```

```java
public class TestStudent {
    public static void main(String[] args) {
        Student stu = new Student();
        System.out.println(stu);

        System.out.println(stu.name);
        System.out.println(stu.age);

        stu.name = "张三";
        stu.age = 23;

        System.out.println(stu.name);
        System.out.println(stu.age);

        stu.study();
        stu.eat();
    }
}
```

说明：`System.out.println(stu)` 打印的是对象 stu 的地址值。

### 3.2 两个对象内存图

1. 一个类可以创建多个对象，每个对象在堆内存中拥有自己独立的内存空间
1. 两个对象的成员变量互不影响：stu1 的 name 为张三、age 为 23，stu2 的 name 为李四、age 为 24
1. 成员方法由所有对象共享，两个对象调用的是同一个方法

```java
public class Test {
    public static void main(String[] args) {
        Student stu1 = new Student();
        stu1.name = "张三";
        stu1.age = 23;

        Student stu2 = new Student();
        stu2.name = "李四";
        stu2.age = 24;

        System.out.println(stu1.name);
        System.out.println(stu2.age);

        stu1.study();
        stu2.study();
    }
}
```

### 3.3 两个引用指向同一对象

1. `Student stu2 = stu1;` 表示 stu2 也指向 stu1 所指向的那个对象
1. 两个引用指向同一块堆内存，通过任何一个引用修改数据，另一个引用看到的值都会改变
1. 示例：先给 stu1.name 赋值为"钢门吹雪"，再 stu2.name 赋值为"西域狂鸭"，最后打印 stu1.name 和 stu2.name 都是"西域狂鸭"

```java
public class Test {
    public static void main(String[] args) {
        Student stu1 = new Student();
        stu1.name = "钢门吹雪";

        Student stu2 = stu1;
        stu2.name = "西域狂鸭";

        System.out.println(stu1.name);
        System.out.println(stu2.name);
    }
}
```

## 4. 成员变量和局部变量的区别

### 4.1 区别对比表

| 区别 | 成员变量 | 局部变量 |
| --- | --- | --- |
| 类中位置不同 | 方法外 | 方法中 |
| 初始化值不同 | 有默认初始化值 | 没有，使用之前需要完成赋值 |
| 内存位置不同 | 堆内存 | 栈内存 |
| 生命周期不同 | 随着对象的创建而存在，随着对象的消失而消失 | 随着方法的调用而存在，随着方法的运行结束而消失 |
| 作用域 | 在自己所归属的大括号中 | 在自己所归属的大括号中 |

说明：局部变量的作用域同样局限于自己所属的大括号（所在方法）中。

### 4.2 内存分析

1. 成员变量属于对象，存放在堆内存中，有默认初始化值，随对象的创建而存在
1. 局部变量属于方法，存放在栈内存中，没有默认值，必须赋值后才能使用，随方法的调用而存在

```java
public class Student {

    String name = "张三";

    public void method(){
        int age = 23;
    }
}
```

生命周期示例：

```java
public class Student {
    String name;
}
```

```java
public class StudentTest {
    public static void main(String[] args) {
        System.out.println("开始");
        method();
        System.out.println("结束");
    }

    public static void method() {
        Student stu = new Student();
        stu.name = "钢门吹雪";
    }
}
```

说明：method 方法调用结束后，局部变量 stu 随之从栈内存消失；堆内存中不再被引用的对象也会随之失去存在意义。

## 5. this 关键字

### 5.1 this 可以解决的问题

1. 当局部变量和成员变量出现了重名的情况，Java 使用的是就近原则
1. 例如 `sayHello(String name)` 方法中直接输出 `name`，使用的是局部变量 name

```java
public class Student {
    String name;
    int age;

    public void sayHello(String name) {
        System.out.println(name);
    }
}
```

```java
Student stu = new Student();
stu.name = "钢门吹雪";
stu.age = 23;
stu.sayHello("西域狂鸭");
```

输出结果：西域狂鸭（就近原则，使用的是局部变量 name）。

### 5.2 this 的介绍

1. `this` 代表当前类对象的引用（地址）
1. `this` 关键字的作用是调用本类成员
    1. `this.本类成员变量;`：如果不涉及变量重复，`this.` 可以省略
    1. `this.本类成员方法();`：没有前提条件，`this.` 可以直接省略

```java
public class Student {
    String name;
    int age;

    public void sayHello(String name) {
        System.out.println(this.name);
    }
}
```

输出结果：钢门吹雪（`this.name` 访问的是成员变量 name）。

### 5.3 this 内存图

1. 栈内存中，main 方法的局部变量 `Student stu` 保存对象的地址（0011）
1. 调用 `stu.sayHello("西域狂鸭")` 时，sayHello 方法的栈帧中保存调用者信息：this 指向 stu，也就是地址 0011
1. 方法内输出：`sout("局部变量:" + name)` 输出"局部变量：西域狂鸭"，`sout("成员变量:" + this.name)` 输出"成员变量：钢门吹雪"

```java
class Student {
    String name;
    int age;
    public void sayHello(String name){
        sout("局部变量:" + name);
        sout("成员变量:" + this.name);
    }
}
```

```java
public static void main(String[] args) {
    Student stu = new Student();
    stu.name = "钢门吹雪";
    stu.age = 23;
    stu.sayHello("西域狂鸭");
}
```

```text
局部变量：西域狂鸭
成员变量：钢门吹雪
```

### 5.4 小结

1. 当局部变量和成员变量重名的时候，Java 使用的是就近原则
1. `this` 关键字的作用是调用本类成员
1. `this` 代表当前类对象的引用（地址）

## 6. 构造方法

### 6.1 构造方法介绍

1. 构造器：初始化一个新建的对象，是构建、创造对象的时候所调用的方法
1. 格式：
    1. 方法名与类名相同，大小写也要一致
    1. 没有返回值类型，连 `void` 都没有
    1. 没有具体的返回值（不能由 `return` 带回结果数据）
1. 执行时机：
    1. 创建对象的时候调用，每创建一次对象，就会执行一次构造方法
    1. 不能手动调用构造方法

```java
public class Test {
    public static void main(String[] args) {
        Student stu = new Student();
    }
}
```

### 6.2 构造方法的作用

1. 本质作用：创建对象
1. 结合构造方法执行时机：给对象中的属性（成员变量）进行初始化

### 6.3 构造方法的注意事项

1. 构造方法的创建：
    1. 如果没有定义构造方法，系统将给出一个默认的无参数构造方法
    1. 如果定义了构造方法，系统将不再提供默认的构造方法
1. 构造方法的重载：构造方法也是方法，允许重载关系出现
1. 推荐的使用方式：无参数构造方法，和带参数构造方法，都自己手动给出

```java
class Student {
    int age;

    public Student() {

    }

    public Student(int age) {
        this.age = 18;
    }
}
```

### 6.4 构造方法执行流程

执行 `Student stu = new Student("钢门吹雪", 23);` 的过程：

1. 在堆内存中为对象分配空间，成员变量有默认值（name 为 null，age 为 0）
1. 调用构造方法 `Student(String name, int age)`，构造方法中 this 指向新创建的对象（地址 0011）
1. 构造方法执行赋值：name 变为"钢门吹雪"，age 变为 23
1. 构造方法执行结束，把对象地址值赋给 stu

```java
public class Student {
    String name;
    int age;
    public Student() {
    }
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    public void show() {
        sout(name + "---" + age);
    }
}
```

```java
public static void main(String[] args) {
    Student stu = new Student("钢门吹雪",23);
    stu.show();
}
```

### 6.5 小结

1. 构造方法的作用：
    1. 创建对象
    1. 给成员变量初始化
1. 构造方法的格式：
    1. 方法名与类名相同，大小写也要一致
    1. 没有返回值类型，连 `void` 都没有
    1. 没有具体的返回值
1. 构造方法的注意事项：
    1. 如果一个类中没写构造方法，系统会提供一个默认的无参构造方法
    1. 如果手动编写了构造方法，系统将不会提供默认的那个无参构造
    1. 建议：无参构造、带参构造全部手动给出

## 7. 封装

### 7.1 面向对象三大特征

1. 封装
1. 继承
1. 多态

### 7.2 封装思想

1. 使用类设计对象时，将需要处理的数据以及处理这些数据的方法设计到对象中
1. 封装就是将数据（属性）和操作数据的方法捆绑在一起，组成一个整体，也就是类
1. 同时，通过访问修饰符来控制对类中属性和方法的访问权限，从而实现信息隐藏
1. 使用封装设计类的时候，要做到合理隐藏、合理暴露

### 7.3 例子：学生成绩管理

需求：计算出每一名学生的总成绩，展示学生的所有信息。

学生数据：

| id | 姓名 | 年龄 | 数学成绩 | 语文成绩 |
| --- | --- | --- | --- | --- |
| 1 | 张三 | 23 | 90 | 87 |
| 2 | 李四 | 24 | 69 | 91 |

方式一：不使用类，用大量分散的变量保存数据，数据与方法分离，难以维护：

```java
int id1 = 1;
int id2 = 2;
String name1 = "张三";
String name2 = "李四";
int age1 = 23;
int age2 = 24;
double mathScore1 = 90;
double mathScore2 = 69;
double chineseScore1 = 87;
double chineseScore2 = 91;
Student stu1 = new Student(1, "张三", 23,90,87);
Student stu2 = new Student(2, "李四", 24,69,91);
```

方式二：使用类把数据和操作数据的方法封装在一起：

```java
public class Student {
    int id;
    String name;
    int age;
    double mathScore;
    double chineseScore;

    public Student(int id, String name, int age, double mathScore, double chineseScore) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.mathScore = mathScore;
        this.chineseScore = chineseScore;
    }
}
```

在类中加入处理数据的方法：

```java
public class Student {
    int id;
    String name;
    int age;
    double mathScore;
    double chineseScore;

    // 省略构造方法

    public double getTotalScore() {
        return mathScore + chineseScore;
    }

    public void showStudentInfos(){
        System.out.println("学号: " + id);
        System.out.println("姓名: " + name);
        System.out.println("年龄:" + age);
        System.out.println("数学成绩:" + mathScore);
        System.out.println("语文成绩:" + chineseScore);
    }
}
```

调用者只需要创建对象并调用方法，无需关心内部实现：

```java
public class Test {
    public static void main(String[] args) {
        Student stu1 = new Student(1, "张三", 23,90,87);
        stu1.showStudentInfos();

        Student stu2 = new Student(2, "李四", 24,69,91);
        stu2.showStudentInfos();
    }
}
```

封装的好处：

1. 更好的维护数据
1. 使用者无需关心内部实现，只要知道如何使用即可

### 7.4 已有对象的封装

1. `Random`：创建对象后调用 `nextInt` 方法，无需关心随机数的内部实现

```java
Random r = new Random();
int num = r.nextInt(100) + 1;
```

1. `Scanner`：创建对象后调用 `nextInt` 方法，无需关心键盘录入的内部实现

```java
Scanner sc = new Scanner(System.in);

```

### 7.5 合理隐藏、合理暴露

1. 例：手机 `call()` 方法内部需要调用保存通话记录的方法 `saveLog()`
1. `saveLog()` 属于内部细节，设置为 `private`，外部无法直接调用
1. `call()` 对外暴露，使用者只需要打电话，不需要关心通话记录是如何保存的

```java
public class Phone {

    public void call(String name) {
        System.out.println("给" + name + "打电话");
        saveLog();
    }

    public void saveLog(){
        System.out.println("通话记录");
        System.out.println("将联系人-时间-通话时长保存到本地");
    }

}
```

把 `saveLog()` 改为 `private` 之后，测试类中直接 `p.saveLog();` 会报错，只能通过 `p.call();` 间接调用：

```java
public class Phone {

    public void call(String name) {
        System.out.println("给" + name + "打电话");
        saveLog();
    }

    private void saveLog(){
        System.out.println("通话记录");
        System.out.println("将联系人-时间-通话时长保存到本地");
    }

}
```

### 7.6 权限修饰符

1. 四种权限修饰符：`private`、(default)、`protected`、`public`
1. 它们可以修饰成员变量、成员方法、构造方法，控制类中成员和方法的访问权限

### 7.7 小结

1. 封装是一种思想
1. 封装就是将数据（属性）和操作数据的方法捆绑在一起，组成一个整体，也就是类
1. 通过访问修饰符来控制对类中属性和方法的访问权限，从而实现信息隐藏
1. 使用封装设计类的时候，要做到合理隐藏，合理暴露
1. 权限修饰符：`private`、(default)、`protected`、`public`

## 9. static 关键字

### 9.1 static 概述

1. `static` 是静态的意思
1. 可以修饰成员变量，也可以修饰成员方法

### 9.2 static 修饰成员的特点

1. 被其修饰的成员，被该类的所有对象所共享
1. 多了一种调用方式，可以通过类名调用
1. 随着类的加载而加载，优先于对象存在

### 9.3 static 内存图

以"在线人数"为例：

1. 静态成员变量 `onLineNumber` 存放在方法区的 User 静态成员变量区，被所有对象共享
1. 无论通过 `User.onLineNumber++` 还是对象名调用，修改的都是同一个变量
1. 输出结果：u1 输出"张三---23---1"，u2 输出"李四---24---2"，在线人数递增

```java
class User {
    String name;
    int age;
    static int onLineNumber;
}
public class StaticTest1 {
    public static void main(String[] args) {
        User.onLineNumber++;
        User u1 = new User();
        u1.name = "张三";
        u1.age = 23;
        sout(u1.name + "---" + u1.age
            + "---" + u1.onLineNumber);
        User.onLineNumber++;
        User u2 = new User();
        u2.name = "李四";
        u2.age = 24;
        sout(u2.name + "---" + u2.age
            + "---" + u2.onLineNumber);
    }
}
```

```text
张三---23---1
李四---24---2
```

### 9.4 使用场景

1. `static` 成员变量：用于需要共享的数据
1. `static` 成员方法：常用于工具类，工具类的方法大多数是 `static` 的

### 9.5 注意事项

1. `static` 方法中，只能访问静态成员（直接访问）
1. `static` 中不允许使用 `this` 关键字

### 9.7 重新认识 main 方法

```java
public class HelloWorld {
    public static void main(String[] args) {
	System.out.println("HelloWorld");
    }
}
```

1. `public`：被 JVM 调用，访问权限足够大
1. `static`：被 JVM 调用，不用创建对象；因为 main 方法是静态的，所以测试类中其他方法也需要是静态的
1. `void`：被 JVM 调用，不需要给 JVM 返回值
1. `main`：一个通用的名称，虽然不是关键字，但是被 JVM 识别
1. `String[] args`：以前用于接收键盘录入数据的，现在没用

### 9.8 小结

1. `static` 是静态修饰符，可用来修饰成员变量、成员方法
1. 修饰成员的特点：
    1. 被其修饰的成员，被该类的所有对象所共享
    1. 多了一种调用方式，可以通过类名调用
    1. 随着类的加载而加载，优先于对象存在
1. 使用场景：
    1. 成员变量：需要共享的数据
    1. 成员方法：工具类的方法大多数是 `static` 的
1. 注意事项：静态方法中只能访问静态成员（直接访问），静态中没有 `this` 关键字
