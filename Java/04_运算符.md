## 1. 算数运算符

### 1.1 算数运算符分类

| 符号 | 作用 | 说明 |
| --- | --- | --- |
| + | 加 | 参看小学一年级 |
| - | 减 | 参看小学一年级 |
| * | 乘 | 参看小学二年级，与“×”相同 |
| / | 除 | 参看小学二年级，与“÷”相同 |
| % | 取余 | 获取的是两个数据做除法的余数 |

### 1.2 除法和取余的区别

/ 和 % 的区别：两个数据做除法，/ 取结果的商，% 取结果的余数。

- 整数操作只能得到整数，要想得到小数，必须有浮点数参与运算。

注意事项：`/` 得到的是商，`%` 得到的是余数，两者不要混淆。

### 1.3 数值拆分

需求：将数字 123 拆分出个位、十位、百位后，打印在控制台。

分析：

- 个位的计算：`数值 % 10`（123 除以 10，商 12，余数为 3）
- 十位的计算：`数值 / 10 % 10`（123 除以 10，商 12，余数为 3，整数相除只能得到整数；12 除以 10，商 1，余数为 2）
- 百位的计算：`数值 / 10 / 10 % 10`（123 / 10 得到 12，12 / 10 得到 1，1 % 10 得到 1）

运行结果：

```text
整数123的个位为:3
整数123的十位为:2
整数123的百位为:1
```

公式总结：

- 个位：`数值 % 10`
- 十位：`数值 / 10 % 10`
- 百位：`数值 / 10 / 10 % 10`
- 千位：`数值 / 10 / 10 / 10 % 10`
- 以此类推

课堂问题：

- 整数相除可以直接得到小数结果吗？如果不可以该怎么解决？
  - 不可以，需要加入小数运算。
- 假设给定一个五位数 65536，获取千位的计算公式是？
  - `数值 / 10 / 10 / 10 % 10;`

## 2. 字符串拼接

### 2.1 拼接规则

当 + 操作中，遇到了字符串，这时 + 就是字符串连接符，而不是算术运算。

### 2.2 基本示例

代码：

```java
public class Test {
    public static void main(String[] args) {
                System.out.println(1 + 23);
        System.out.println("年龄为:" + 23);
        System.out.println(1 + 99 + "年");
    }
}
```

运行结果：

```text
24
年龄为：23
100年黑
```

说明：

- `1 + 23`：两个整数相加，结果是 24
- `"年龄为:" + 23`：遇到了字符串，+ 变成字符串连接符，结果是 “年龄为：23”
- `1 + 99 + "年黑马"`：从左到右，先算 `1 + 99` 得到 100，再和字符串拼接，结果是 “100年黑马”

### 2.3 连续拼接与括号

代码：

```java
public class Test {
    public static void main(String[] args) {
        System.out.println("年龄为:" + 23 + 1);
    }
}
```

运行结果：`年龄为：231`

拼接过程：`"年龄为:" + 23` 得到 `"年龄为:23"`，再 `+ 1`，此时 + 仍然是字符串连接符，得到 `"年龄为:231"`。

代码：

```java
public class Test {
    public static void main(String[] args) {
        System.out.println("年龄为:" + (23 + 1) );
    }
}
```

运行结果：`年龄为：24`

说明：括号优先级最高，先计算 `23 + 1` 得到 24，再进行字符串拼接。

### 2.4 小结

当 + 号操作中遇到了字符串，就会变成字符串拼接。

## 3. 自增自减运算符

### 3.1 基本用法

| 符号 | 作用 | 说明 |
| --- | --- | --- |
| ++ | 自增 | 变量自身的值加 1 |
| -- | 自减 | 变量自身的值减 1 |

++ 和 -- 既可以放在变量的后边，也可以放在变量的前边。

### 3.2 使用规则

- ++、-- 单独使用在前在后无区别
- 参与运算使用：
  - ++ 在前，先自增再操作
  - ++ 在后，先操作再自增
- ++、-- 只能操作变量不能操作字面量

## 4. 类型转换

### 4.1 隐式转换

隐式转换：把一个取值范围小的数值或者变量，赋值给另一个取值范围大的变量。

取值范围从小到大：`byte` → `short` → `char` → `int` → `long` → `float` → `double`

代码示例（int 自动转成 double）：

```java
public class Test {
    public static void main(String[] args) {
        int a = 10;
        double b = a;
        System.out.println(b);
    }
}
```

运行结果：`10.0`

说明：可以理解为 int 是 4 升的桶，double 是 8 升的桶，小桶里的水倒进大桶没有问题，赋值自动完成。

### 4.2 运算中的隐式转换

取值范围小的数据，和取值范围大的数据进行运算，小的会先提升为大的之后，再进行运算。

代码示例（a 是 int，b 是 double，a 先提升为 double 再相加，结果需要 double 类型接收）：

```java
public class Test {
    public static void main(String[] args) {
        int a = 10;
        double b = 12.3;
        数据类型 c = a + b;
    }
}
```

“数据类型”处应写 `double`：

```java
public class Test {
    public static void main(String[] args) {
        int a = 10;
        double b = 12.3;
        double c = a + b;
    }
}
```

byte short char 三种数据在运算的时候，都会提升为 int，然后再进行运算。

错误示例（byte 与 byte 相加结果提升为 int，不能直接赋给 byte）：

```java
public class Test {
    public static void main(String[] args) {
        byte a = 10;
        byte b = 20;
        byte c = a + b;
    }
}
```

正确写法（用 int 接收）：

```java
public class Test {
    public static void main(String[] args) {
        byte a = 10;
        byte b = 20;
        int c = a + b;
    }
}
```

char 参与运算时也会提升为 int：

```java
public class Test {
    public static void main(String[] args) {
        int a = 1;
        char b = 'a';
        int c = a + b;
        System.out.println(c);
    }
}
```

运行结果：`98`

说明：字符 `'a'` 的编码值是 97，97 + 1 = 98。

### 4.3 强制类型转换

把一个取值范围大的数值或者变量，赋值给另一个取值范围小的变量，不允许直接赋值，需要加入强制转换。

格式：`目标数据类型 变量名 = (目标数据类型) 被强转的数据;`

代码示例：

```java
public class Test {
    public static void main(String[] args) {
        double a = 12.3;
        int b = (int) a;
        System.out.println(b);
    }
}
```

运行结果：`12`

说明：直接写 `int b = a;` 会报错，必须写成 `int b = (int) a;`；强制转换只保留整数部分，舍弃小数部分，有可能造成精度损失。

### 4.4 类型转换小结

- 基本的隐式转换：把一个取值范围小的数值或者变量，赋值给另一个取值范围大的变量
- 运算中的隐式转换：
  - 取值范围小的数据，和取值范围大的数据进行运算，小的会先提升为大的之后，再进行运算
  - byte short char 三种数据在运算的时候，都会提升为 int，然后再进行运算
- 强制类型转换：
  - 取值范围大的数据，给取值范围小的变量赋值，需要强制类型转换
  - 强转有可能造成精度损失

## 5. 赋值运算符

### 5.1 赋值运算符分类

| 符号 | 作用 | 说明 |
| --- | --- | --- |
| = | 赋值 | a=10，将 10 赋值给变量 a |
| += | 加后赋值 | a+=b，将 a + b 的值给 a |

| *= | 乘后赋值 | a*=b，将 a × b 的值给 a |
| /= | 除后赋值 | a/=b，将 a ÷ b 的商给 a |
| %= | 取余后赋值 | a%=b，将 a ÷ b 的余数给 a |

### 5.2 使用要点

- 基本赋值运算符：`=`
- 扩展赋值运算符：`+=`、`-=`、`*=`、`/=`、`%=`
- 扩展赋值运算符隐含了强转效果

## 6. 关系运算符

### 6.1 关系运算符分类

| 符号 | 说明 |
| --- | --- |
| == | a==b，判断 a 和 b 的值是否相等，成立为 true，不成立为 false |
| != | a!=b，判断 a 和 b 的值是否不相等，成立为 true，不成立为 false |
| > | a>b，判断 a 是否大于 b，成立为 true，不成立为 false |
| >= | a>=b，判断 a 是否大于等于 b，成立为 true，不成立为 false |
| < | a<b，判断 a 是否小于 b，成立为 true，不成立为 false |
| <= | a<=b，判断 a 是否小于等于 b，成立为 true，不成立为 false |

### 6.2 使用要点

- 关系运算符：`>`、`>=`、`<`、`<=`、`==`、`!=`
- 最终返回的都是 boolean 类型的结果
- `==` 和 `=` 号不要弄混淆了（`==` 是比较是否相等，`=` 是赋值）

## 7. 逻辑运算符

### 7.1 引入

需求：在程序中，判断一个学生成绩是否在 90~100 之间，是的话程序输出优秀。

代码示例：

```java
public class Test {
    public static void main(String[] args) {
        int score = 95;
        System.out.println(score >= 90);
        System.out.println(score <= 100);
    }
}
```

运行结果：`true`、`true`

说明：

- 逻辑运算符连接布尔类型的表达式，或者是值
- 把多个条件放在一起运算，最终返回布尔类型的值：true、false

### 7.2 逻辑运算符分类

| 符号 | 介绍 | 说明 |
| --- | --- | --- |
| & | 逻辑与 | 并且，遇 false 则 false |
| \| | 逻辑或 | 或者，遇 true 则 true |
| ! | 逻辑非 | 取反 |
| ^ | 逻辑异或 | 相同为 false，不同为 true |

### 7.3 短路逻辑运算符

| 符号 | 介绍 | 说明 |
| --- | --- | --- |
| && | 短路与 | 作用和 & 相同，但是有短路效果 |
| \|\| | 短路或 | 作用和 \| 相同，但是有短路效果 |

- 逻辑与 `&`：无论左边 true false，右边都要执行
- 短路与 `&&`：如果左边为 true，右边执行，如果左边为 false，右边不执行
- 逻辑或 `|`：无论左边 true false，右边都要执行
- 短路或 `||`：如果左边为 false，右边执行，如果左边为 true，右边不执行
- 最常用的逻辑运算符：`&&`、`||`、`!`

### 7.4 逻辑运算符小结

- `&`：遇 false 则 false
- `&&`：左边为 false，右边不执行
- `|`：遇 true 则 true
- `||`：左边为 true，右边不执行了
- `!`：取反
- `^`：相同是 false、不同是 true

注意：实际开发中常用的逻辑运算符是：`&&`、`||`、`!`

## 8. 三元运算符

### 8.1 格式与执行流程

格式：`判断条件 ? 值1 : 值2;`

执行流程：

1. 首先计算判断条件的值
1. 如果值为 true，值 1 就是运算结果
1. 如果值为 false，值 2 就是运算结果

总结：根据判断条件，从两份数据中二者选其一。

## 9. 运算符优先级

### 9.1 优先级表

下表按优先级从高到低排列：

| 优先级 | 运算符 |
| --- | --- |
| 1 | `.`、`()`、`{}` |
| 2 | `!`、`~`、`++`、`--` |
| 3 | `*`、`/`、`%` |
| 4 | `+`、`-` |
| 5 | `<<`、`>>`、`>>>` |
| 6 | `<`、`<=`、`>`、`>=`、`instanceof` |
| 7 | `==`、`!=` |
| 8 | `&` |
| 9 | `^` |
| 10 | `\|` |
| 11 | `&&` |
| 12 | `\|\|` |
| 13 | `?:` |
| 14 | `=`、`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`\|=`、`^=`、`<<=`、`>>=`、`>>>=` |

### 9.2 优先级示例

代码：

```java
public class Test {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;
        System.out.println(a > b || a < b && a > b);
    }
}
```

运算过程（`&&` 的优先级高于 `||`，先算 `&&` 再算 `||`）：

1. `a > b`：10 > 20，结果为 false
1. `a < b`：10 < 20，结果为 true
1. `a > b`：10 > 20，结果为 false
1. `a < b && a > b`：true && false，结果为 false
1. `a > b || a < b && a > b`：false || false，结果为 false

使用括号改变优先级：

1. `(a > b || a < b) && a > b`：(false || true) && false → true && false，结果为 false
1. `a > b || (a < b && a > b)`：false || (true && false) → false || false，结果为 false

### 9.3 小结

- 优先级越高的运算符越先执行
- 可以使用括号 `()` 改变运算顺序，括号内先算

## 10. Scanner 键盘录入

### 10.1 需求与原理

需求：请在程序中，提示用户通过键盘输入自己的姓名、年龄，并能在程序中收到这些数据。

原理：Java 已经写好了实现程序，我们调用即可。JDK 中包含 JRE 和 javac、java 等开发工具，JRE 中包含核心类库和 JVM，Scanner 就是 JDK 提供好的现成类。

### 10.2 使用步骤

使用 Scanner 接收用户键盘输入的数据，需要三个步骤：

1. 导包：`import java.util.Scanner;`（告诉程序去 JDK 的哪个包中找扫描器技术）
1. 创建对象：`Scanner sc = new Scanner(System.in);`（得到键盘扫描器对象）
1. 调用方法接收数据（等待接收用户输入数据）：

   1. `sc.nextInt()` 接收整数
   1. `sc.next()` 接收字符串
   1. `sc.nextDouble()` 接收浮点数

### 10.3 完整代码示例

```java
import java.util.Scanner;
public class Test {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("请输入您的年龄：");
        int age = sc.nextInt();
        System.out.println("年龄是：" + age);

        System.out.println("请输入您的名称： ");
        String name = sc.next();
        System.out.println("欢迎： " + name);
    }
}
```
