# lining-lo-notes

学习笔记仓库，模仿 [EveryDay](https://github.com/WindRunnerMax/EveryDay) 的"低摩擦写作 + 自动发布"闭环：只写 Markdown，脚本自动维护目录、统计、时间线，并构建博客发布到 GitHub Pages。

- 按学习顺序阅读：[Timeline](./Timeline.md)
